# Goal

Initialize the Java 17 foundation of the AeonFlux Android Client with Room database schemas, Hilt wiring, and background ExoPlayer services.

# Details

## Context

The Android client needs to handle RSS feed ingestion, database persistence for feeds/items, and high-performance audio playback. The project was recently migrated to Java, and we need to scaffold the core components with strict null safety and dependency injection.

## Requirements

- [ ] [TSK-20260804-002.1] **Dependency Injection Configuration**: Setup Dagger Hilt annotations and Android entry point configurations in `MainActivity` and `AeonFluxApplication`.
- [ ] [TSK-20260804-002.2] **Room Database Schemas**: Configure Room entities (`FeedEntity`, `FeedItemEntity`) and DAOs (`FeedDao`) with standard relational mappings.
- [ ] [TSK-20260804-002.3] **Audio Playback Service**: Implement the background playback engine using Android Media3 ExoPlayer inside `PlaybackService`.
