# Task TSK-20260805-001: MainActivity Navigation, Feed Tree, Gestures, ItemViewActivity, and Settings

## Goal
Implement full UI navigation in `MainActivity` with a left navigation drawer for feeds/sources tree, right/end panel, dynamic infinite scrolling item list with gestures, a 3-dots option menu with filtering/sorting/grouping, `ItemViewActivity` for article details/actions, and `SettingsActivity`.

## Context & Requirements

### Functional Requirements
* **[REQ-00010] Navigation & Drawer Layouts**:
  * Implement standard dual navigation layout in `MainActivity` (Left Drawer for Feeds/Sources Tree, Right/End panel for foldable quick view/details).
* **[REQ-00020] Feeds/Sources Tree Navigation**:
  * Display list of feeds/sources with name and unread item counts.
  * When grouped by label: first level displays groups/labels, second level displays feeds/sources. If a feed has multiple labels, it appears under each label group.
* **[REQ-00030] Feed Items List & Infinite Scroll**:
  * Dynamic list backed by Room SSOT reactivity (`LiveData`/`Paging`).
  * Infinite scroll loading for paginated feed items.
* **[REQ-00040] Touch Gestures**:
  * Swipe top-to-bottom at top of list: Pull-to-refresh feeds/sources.
  * Swipe item left-to-right: Discard / mark item as read.
  * Scroll up/down: Standard vertical list navigation.
  * Item Click: Launch `ItemViewActivity`.
  * Customizable component wrapper per item snippet.
* **[REQ-00050] Options Menu (3-dots)**:
  * Open `SettingsActivity`.
  * Force refreshing of feeds/sources.
  * Toggle grouping by labels. When active, update left drawer tree and filter item list by selected label group or single source.
  * Sort feeds/sources in left drawer by: Last fetch timestamp (ASC/DESC), Last article timestamp (ASC/DESC), Alphabetical (ASC/DESC).
  * Sort/Filter items in main list by: Timestamp (ASC/DESC), Show/hide old items, Show/hide read items.
* **[REQ-00060] ItemViewActivity**:
  * Display item metadata (summary, timestamp, labels, keywords, read/unread status, new/not-new status).
  * Action menu: Download article/attachments, WebView display (normal or private mode), Label association, Toggle "starred" bookmark status.
* **[REQ-00070] SettingsActivity**:
  * Basic app-wide parameters (refresh intervals, theme modes, storage caps).
