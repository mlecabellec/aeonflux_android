# Goal

Initialize a SQLite (via Room) database for storing sources, articles, keywords, labels, properties, secrets, and settings. Implement a centralized service to handle CRUD operations and event callbacks.

# Details

## Context

The application needs an offline-first data model capable of storing feeds (renamed to sources), articles, metadata, dynamic properties, settings, and encrypted credentials. A centralized data service is needed to manage these entities reactively and support lifecycle events (hooks) for CRUD actions.

- [x] [TSK-20260804-003.1] **Data Model Design & Refactoring**: Refactor `FeedEntity` and `FeedItemEntity` to `SourceEntity` and `ArticleEntity`. Create entities for `KeywordEntity`, `LabelEntity`, cross-reference tables, EAV `PropertyEntity`, `SourceSecretEntity`, and `SettingEntity`.
- [x] [TSK-20260804-003.2] **Cryptographic Storage**: Implement AES-GCM encryption helper backed by Android Keystore to encrypt and decrypt source secrets before storage.
- [x] [TSK-20260804-003.3] **Database Seeding**: Support database seeding via `RoomDatabase.Callback` upon installation/first launch.
- [x] [TSK-20260804-003.4] **Centralized Database Service**: Implement a thread-safe `DatabaseService` with CRUD APIs, transactions, and an observer system supporting `OnEntityChangeListener` callbacks.
- [x] [TSK-20260804-003.5] **Documentation & Diagrams**: Update project documentation and compile the data model diagrams.
