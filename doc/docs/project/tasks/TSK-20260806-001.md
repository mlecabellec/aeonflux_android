# Task TSK-20260806-001: OPML Import/Export Capability & Background RSS Fetching Service

## Goal
Implement full OPML feed import and export capabilities, UI navigation integration in `MainActivity`'s left drawer, manual feed creation activity, OPML progress/logging activities, and a background RSS fetching service using WorkManager with CRON-like schedule support and battery constraint compliance.

## Context & Requirements

### Functional Requirements
* **[REQ-OPML-001] OPML Import**:
  * Parse OPML files (supporting versions 1.0, 1.1, 2.0, Feeder extensions, PocketCasts, and nested outline group categories).
  * Ignore already existing feeds using `xmlUrl` as a unique key.
  * Map nested outline titles to database `Label` entities.
  * Perform feed URL accessibility check and seed initial article fetching.
  * Real-time progress and log reporting in UI (`ImportOpmlActivity`).
* **[REQ-OPML-002] OPML Export**:
  * Export selected/all sources and associated labels into a standardized OPML format using SAF file pickers (`ExportOpmlActivity`).
* **[REQ-OPML-003] MainActivity Drawer Commands**:
  * Add source command launching `AddSourceActivity`.
  * Foldable Import/Export command container launching `ImportOpmlActivity` and `ExportOpmlActivity`.
* **[REQ-FETCH-001] Background RSS Fetching Service**:
  * Add CRON-like fetch interval scheduling to `SourceEntity` / `SourceDTO`.
  * Implement background fetching via `WorkManager` with `NETWORK_CONNECTED` and `BATTERY_NOT_LOW` constraints.

### Architectural Rules Compliance (CS-0010, CS-0020, CS-0030)
* Traceability annotations (`REQ-OPML-001`, `REQ-FETCH-001`, `TSK-20260806-001`) on all code blocks.
* Defensive precondition checks (`Objects.requireNonNull`) and range validations.
* Absolute null safety (return empty lists/DTOs).
* Explicit Java typing (no `var`).
* Comprehensive JUnit & integration test coverage including `podcasts_opml.xml` and `feeder-export-2026-01-20-67634.opml`.
* Dual-method verification (JUnit test suite + adb runtime verification).
