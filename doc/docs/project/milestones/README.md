# Project Milestones

This directory tracks the major milestones for the AeonFlux Client project.
Currently planned milestones:

*   **M1: Scaffolding & Setup** (Current) - Initialize documentation structure, build scripts, static linters, and DI framework.
*   **M2: Local Ingestion & Persistence** - Implement local feed database indexing and offline synchronization workflows.
*   **M3: Background Audio Delivery** - Implement background audio media player using ExoPlayer.
