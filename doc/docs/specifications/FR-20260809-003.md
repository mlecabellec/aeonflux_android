# Feature Request: FR-20260809-003

## Title
Vosk On-Device Speech Recognition Engine & About Application Activity

## Description
This feature request integrates the 100% on-device Vosk Speech Recognition API abstraction (`VoskTranscriptEngine`) into `AudioPlaybackActivity` with dynamic Karaoke speech-to-text scrolling and a manual enablement toggle button (**disabled by default**). Furthermore, it introduces `AboutActivity` featuring an embedded local HTML web page (`about.html`) presenting software details, authors, and open-source licenses.

---

## Technical Specifications & Requirements

### 1. About Activity & Web Asset (`AboutActivity`)
- **[TSK-20260809-003.1]**:
  - Implement `AboutActivity` loading local asset `file:///android_asset/about.html`.
  - Display application overview, platform version, and third-party software attribution (Vosk API Apache 2.0, AndroidX, Dagger Hilt, Room ORM, DeepLearning4j, ZeroMQ).
  - Register `AboutActivity` in `AndroidManifest.xml` and wire `action_about` menu item in `MainActivity`.

### 2. Vosk On-Device STT Engine (`VoskTranscriptEngine`)
- **[TSK-20260809-003.2]**:
  - Implement `VoskTranscriptEngine` providing offline speech-to-text transcript decoding.
  - Enforce **disabled-by-default** operational policy (`isEnabled() == false`).

### 3. Audio Playback Activity Karaoke Integration (`AudioPlaybackActivity`)
- **[TSK-20260809-003.3]**:
  - Integrate `VoskTranscriptEngine` into `AudioPlaybackActivity`.
  - Add `btn_toggle_transcription` button in Karaoke header (`"🎤 Enable STT Karaoke"` / `"🎤 Disable STT Karaoke"`).
  - Update `recycler_audio_transcript` dynamically when toggled ON/OFF.
