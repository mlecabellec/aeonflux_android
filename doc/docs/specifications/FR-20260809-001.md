# Feature Request 20260809-001: ItemViewActivity Action Buttons & Embedded/Private WebViews

## Reference
* **ID:** `FR-20260809-001`
* **Task:** `TSK-20260809-001`
* **Compliance Standards:** `CS-0010`, `CS-0020`, `CS-0030`

## Overview

Enhance `ItemViewActivity` with an Action Card Button Group located below the article content to allow users to interact with articles directly via embedded WebViews, hardened private WebViews, external browser routing, dynamic read/unread state management, and URL clipboard copying.

## Detailed Requirements

1. **Embedded WebView (`WebViewActivity` / `TSK-20260809-001.1`):**
   * Displays the article URL within a dedicated embedded `WebView` with progress bar indicator and toolbar navigation back button.
2. **Private WebView (`PrivateWebViewActivity` / `TSK-20260809-001.2`):**
   * Hardened incognito WebView with **JavaScript disabled by default**.
   * 3-dots action menu item `action_toggle_javascript` allowing users to toggle JavaScript on/off.
   * Zero persistence policy: Disables DOM Storage, Web Database, Password Saving, File Access, and Geolocation.
   * Purges all cache, cookies, WebSQL databases, and history on creation and activity destruction (`onDestroy()`).
3. **External Web Browser (`TSK-20260809-001.3`):**
   * Launches default browser application via `Intent.ACTION_VIEW`.
4. **Dynamic Read/Unread Status Toggle (`TSK-20260809-001.3`):**
   * Toggles article read status in `DatabaseService` dynamically.
   * Updates button icon and label immediately ("✓ Mark as Read" / "✓ Mark as Unread").
5. **Clipboard URL Copying (`TSK-20260809-001.3`):**
   * Copies article URL to `ClipboardManager` and displays feedback Toast.
