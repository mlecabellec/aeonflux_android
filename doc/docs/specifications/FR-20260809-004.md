# Feature Request: FR-20260809-004

## Title
Audio VAD Silence Detector & OpenAI Whisper Base Model STT Engine

## Description
This feature request introduces `AudioSilenceDetector`, a dual-threshold RMS energy and duration VAD sentence segmenter that splits incoming audio into 4s-20s sentence portions before Speech-to-Text analysis while preserving precise timestamps. It phases out native SpeechRecognizer and legacy Vosk engines in favor of `WhisperTranscriptEngine`, leveraging OpenAI's Whisper base model (`ggml-base.bin`, MIT License) and MediaCodec 16kHz PCM audio extraction for 100% on-device neural speech recognition across all standard Android hardware architectures (`arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`), with extended real-time verbose logcat diagnostic telemetry.

---

## Technical Specifications & Requirements

### 1. Dual-Threshold VAD Silence Detector (`AudioSilenceDetector`)
- **[TSK-20260809-004.1]**:
  - Implement `AudioSilenceDetector` with `MIN_SEGMENT_MS = 4000L` (4s), `MAX_SEGMENT_MS = 20000L` (20s), and `PAUSE_THRESHOLD_MS = 300L`.
  - Preserve `startMs` and `endMs` timestamps for each sentence portion with RMS energy calculation.

### 2. OpenAI Whisper Base Engine Integration (`WhisperTranscriptEngine`)
- **[TSK-20260809-004.6]**:
  - Implement `PcmAudioExtractor` using `MediaExtractor` and `MediaCodec` to decode 16kHz mono float PCM samples from remote HTTP audio URLs and local files.
- **[TSK-20260809-004.7]**:
  - Implement `WhisperNativeBridge` for native C++ `whisper.cpp` (`ggml-base.bin`, MIT License) JNI interoperability across `arm64-v8a`, `armeabi-v7a`, `x86_64`, and `x86` with 16KB page alignment.
- **[TSK-20260809-004.8]**:
  - Implement `WhisperTranscriptEngine` orchestrating PCM extraction, VAD sentence portioning, and Whisper base model speech recognition.

### 3. Extended Real-Time Diagnostic Logging (`AudioPlaybackActivity`)
- **[TSK-20260809-004.9]**:
  - Add extended verbose logcat telemetry (`AeonFlux_Whisper_Diag` and `AeonFlux_STT_RealtimeDiag`) tracing stream metadata, raw PCM frames, VAD chunk timing, decoded speech text, and 1000ms periodic sound position sync.
