# Feature Request: FR-20260809-002

## Title
Dynamic URL Content-Type Detection and Audio/Video Media Playback Engine

## Description
This feature request introduces automated 2-tier URL content-type classification (regex pattern classifier + asynchronous HTTP HEAD MIME detector) and dedicated, state-of-the-art `AudioPlaybackActivity` and `VideoPlaybackActivity` engines with timeline navigation, jump controls (-30s, -5s, +5s, +30s), speed selection (80%, 100%, 110%, 120%, 150%), and reserved karaoke-style audio transcription layout.

---

## Architectural & Technical Requirements

### 1. URL Content-Type Detection (`UrlContentDetector`)
- **[TSK-20260809-002.1]**:
  - Implement 2-tier classifier:
    - Tier 1: Instant Regex Pattern & File Extension Classifier (Audio: `.mp3`, `.m4a`, `.aac`, `.ogg`, `.wav`, `.flac`, `.opus`, podcast RSS feeds; Video: `.mp4`, `.webm`, `.mkv`, `.m3u8`, `.mov`, YouTube, Vimeo).
    - Tier 2: Asynchronous HTTP `HEAD` request checking `Content-Type` headers (`audio/*`, `video/*`, `text/html`) when file extensions are missing.

### 2. Strategy Pattern Player Engine (`PlayerEngine`)
- **[TSK-20260809-002.2]**:
  - Define `PlayerEngine` interface encapsulating playback operations: `prepare(Uri)`, `play()`, `pause()`, `seekTo(long)`, `setSpeed(float)`, `release()`, `addPlayerListener()`.
  - Implement `MediaPlayerEngine` wrapping Android `MediaPlayer` with `PlaybackParams.setSpeed(float)` support for Android API 26+.

### 3. Audio Playback Activity (`AudioPlaybackActivity`)
- **[TSK-20260809-002.3]**:
  - Implement `AudioPlaybackActivity` with timeline `SeekBar`, position timestamps (`00:00 / 03:45`).
  - Seek jump buttons: `-30s`, `-5s`, `Play/Pause`, `+5s`, `+30s`.
  - Speed selector chips: `0.8x` (80%), `1.0x` (100%), `1.1x` (110%), `1.2x` (120%), `1.5x` (150%).
  - Reserved Karaoke Transcription Container: Dedicated `RecyclerView` for timestamped speech-to-text lines (`AudioTranscriptLine`) with active line highlight styling.

### 4. Video Playback Activity (`VideoPlaybackActivity`)
- **[TSK-20260809-002.4]**:
  - Implement `VideoPlaybackActivity` with `SurfaceView` / `TextureView` for video rendering.
  - Overlay controls with seek slider, jump buttons (`-30s`, `-5s`, `Play/Pause`, `+5s`, `+30s`), and speed selector chips.

### 5. ItemViewActivity Dynamic Action Integration (`ItemViewActivity`)
- **[TSK-20260809-002.5]**:
  - Invoke `UrlContentDetector` when article view is opened.
  - Dynamically display **"🎵 Play Audio Content"** or **"🎬 Play Video Content"** action buttons when media is detected.
