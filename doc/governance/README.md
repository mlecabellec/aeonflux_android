# AeonFlux Android Governance Index

This directory details coding rules and static quality checks.

## Guidelines & Rules

* **Java Code Convention:** Strict Java 17 syntax checks, avoiding any Kotlin code in src.
* **Linters:** PMD and Checkstyle are enforced in the Java build files.
* **Testing:** Minimally 85% line coverage is targeted on core components.
